# Mogged для Horizon

Порт [Mogged](https://github.com/Cranch-fur/Mogged) на [Horizon](https://github.com/horizon-rust/horizon) (Minecraft
Java 26.3 на Rust) в виде нативного мода. Переключайтесь между скином своего аккаунта и двумя своими пресетами одной
клавишей, с плавной анимацией перехода — и другие игроки с модом тоже видят ваш образ.

## Отличия от Fabric-версии

- Нет редактора скинов, выбора файлов и перетаскивания: положите `preset1.png` и `preset2.png` в `config/mogged/` или
  впишите пути и ссылки в `config/mogged.json`. Изменения подхватываются в течение секунды.
- HD-скины уменьшаются до 64×64: Horizon хранит каждый скин в ячейке 64×64.
- Нет плащей, элитр, частиц и поддержки Flashback.
- Игроки с Fabric- и Horizon-версиями друг друга не видят, а на ванильных, Paper- и Fabric-серверах пресеты видите
  только вы.

Настройки (Options → Mods → Mogged): какой скин надеть, модель каждого пресета, длина анимации и эффекты. Там же
переназначается клавиша (<kbd>K</kbd>).

## Требования

| Minecraft | Horizon | Платформа |
|---|---|---|
| 26.3 | Nightly 2026-11-01 (`c9d474d`) | ПК |

Мод встраивается в части Horizon, которые не входят в стабильный API, поэтому привязан к этому Nightly. Нативные моды
не изолированы: они компилируются в игру и работают с вашими правами.

## Установка

1. Положите `mogged-1.1.0.hnmod` в `<инстанс>/horizon-native-mods/` (**Open folder** на странице Mods лаунчера) или
   добавьте этот репозиторий по ссылке на GitHub.
2. Нажмите **Собрать** в строке «Нативная компиляция». Первая сборка скачивает Rust и занимает 20–30 минут.
3. Запустите игру и положите свои пресеты в `config/mogged/`.

## Сборка

Нужен Python 3.11+. На Windows запустите `build.bat`, на Linux и macOS — `./build.sh`. Файл появится в
`target/mogged-1.1.0.hnmod`; скрипт только упаковывает исходники, компилирует их лаунчер. `cargo test` запускает тесты
логики мода.

## Устройство проекта

```
mixins/mogged/horizon-mixin.toml   описание мода: модули и хуки
mixins/mogged/runtime.rs           логика мода (настройки, анимация, протокол) и её тесты
mixins/mogged/glue.rs              связка с игрой: файлы, скины, сообщения, звук
mixins/mogged/*.rs                 по небольшому файлу на каждый хук
tools/package.py                   упаковывает .hnmod
```

Настройки хранятся в `config/mogged.json`, в том же формате, что у Fabric-версии.
